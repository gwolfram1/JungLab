# Jung Lab Website

A static website for the Jung Lab, hosted on GitHub Pages.

## Live Site

Once GitHub Pages is enabled, the site will be at:

**https://gwolfram1.github.io/JungLab/**

## Pages

| File | Page |
|---|---|
| `index.html` | Home — lab mission and Dr. Jung bio |
| `research.html` | Research Groups |
| `members.html` | Lab Members |
| `publications.html` | Publications |
| `style.css` | Shared styles |

## Enabling GitHub Pages

1. Go to **https://github.com/gwolfram1/JungLab/settings/pages**
2. Under **Source**, select **Deploy from a branch**
3. Choose branch: `main`, folder: `/ (root)`
4. Click **Save**
5. Wait ~1 minute, then visit **https://gwolfram1.github.io/JungLab/**

## Updating the Site

Edit any HTML file and push to `main`. GitHub Pages rebuilds automatically within ~1 minute.

## Custom Domain (optional)

To use a university subdomain (e.g. `junglab.cs.youruni.edu`):

1. Ask your university IT to add a `CNAME` DNS record pointing your subdomain at `gwolfram1.github.io`
2. Go to **Settings → Pages** in this repo
3. Enter your subdomain in the **Custom domain** field and save
